## What is Compliance Shield?

Compliance Shield is Engram's built-in sanctions screening service. It checks blockchain addresses against multiple global sanctions databases and returns verifiable results — with cryptographic proofs stored on [Shelby Protocol](https://shelby.xyz).

## Data Sources

| Source | Coverage | Update Frequency |
|---|---|---|
| **OFAC SDN** | US Treasury sanctions (788 crypto addresses) | Every 6 hours |
| **OpenSanctions** | Global sanctions (1,497 crypto addresses) | Every 12 hours |
| **Chainalysis** | Real-time global sanctions oracle | Per-request |
| **Community** | User/agent-submitted reports | Real-time |

## Architecture

All raw compliance data is stored as **plain JSON on Shelby** — human-readable and directly verifiable. PostgreSQL acts as a thin search index with pointers to the Shelby blobs.

```
Agent screens address "0xABC"
        │
        ▼
┌── ComplianceIndex (Postgres) ─────┐
│  Fast indexed lookup across:      │
│  OFAC + OpenSanctions + Community │
└─────────────┬─────────────────────┘
              │
    ┌─────────┴──────────┐
    ▼                    ▼
Screen result         Proof uploaded
returned (~10ms)      to Shelby (async)
```

## Quick Start

<CodeGroup>

```typescript SDK
import { Engram } from '@engramtraining/sdk';

const engram = new Engram({ apiKey: 'sk_live_...' });

const result = await engram.compliance.screen({
  addresses: [{ address: '0xABC...', chain: 'ethereum' }],
});

console.log(result.results[0].status); // "clean" | "sanctioned" | "flagged"
```

```bash cURL
curl -X POST https://api.engram.training/v1/compliance/screen \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "addresses": [{"address": "0xABC...", "chain": "ethereum"}]
  }'
```

</CodeGroup>
