---
title: "Screen Addresses"
api: "POST /v1/compliance/screen"
description: "Screen one or more blockchain addresses against global sanctions lists."
---

## Authentication

This endpoint accepts **both** authentication methods:
- **API Key**: `Authorization: Bearer sk_live_...` (for agents and programmatic access)
- **Developer JWT**: `Authorization: Bearer <jwt>` (for dashboard and OAuth sessions)

Billing is resolved to the developer account in both cases.

## Request

<ParamField body="addresses" type="array" required>
  Array of addresses to screen. Maximum 100 per request.
  <Expandable title="Address Object">
    <ParamField body="address" type="string" required>
      The blockchain address to screen.
    </ParamField>
    <ParamField body="chain" type="string">
      Optional chain identifier: `ethereum`, `bitcoin`, `solana`, `polygon`, `bsc`, `arbitrum`, `optimism`, `avalanche`, `aptos`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="includeCommunity" type="boolean" default="true">
  Include community-submitted reports in the screening results.
</ParamField>

<Note>
  All available data sources (OFAC, OpenSanctions, community reports) are used automatically. No opt-in toggles needed.
</Note>

## Response

<ResponseField name="results" type="array">
  <Expandable>
    <ResponseField name="address" type="string">The screened address.</ResponseField>
    <ResponseField name="chain" type="string">Chain identifier.</ResponseField>
    <ResponseField name="status" type="string">
      One of: `clean`, `sanctioned`, `flagged`, `under_review`.
    </ResponseField>
    <ResponseField name="matches" type="array">
      Array of matches found across data sources.
      <Expandable>
        <ResponseField name="entityId" type="string">Unique entity identifier.</ResponseField>
        <ResponseField name="entityName" type="string">Human-readable entity name (if available).</ResponseField>
        <ResponseField name="source" type="string">Data source: `ofac_sdn`, `opensanctions`, `community`.</ResponseField>
        <ResponseField name="severity" type="string">`critical`, `high`, `medium`, or `low`.</ResponseField>
        <ResponseField name="shelbyUrl" type="string">Direct URL to the entity data on Shelby.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="screenedAt" type="string">ISO 8601 timestamp.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="proof" type="object">
  Verifiable screening proof uploaded to Shelby.
  <Expandable>
    <ResponseField name="screeningId" type="string">Unique proof identifier. Use with `GET /v1/compliance/proof/:id`.</ResponseField>
    <ResponseField name="timestamp" type="string">ISO 8601 screening timestamp.</ResponseField>
    <ResponseField name="resultsHash" type="string">SHA-256 hash of the screening results.</ResponseField>
    <ResponseField name="dataSources" type="array">Data sources used in this screening.</ResponseField>
    <ResponseField name="dataSnapshots" type="object">
      Map of source → `{ blobName, shelbyUrl }` pointing to the exact data snapshot used.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="rateLimit" type="object">
  Freemium rate limit info.
  <Expandable>
    <ResponseField name="freeLimit" type="number">Free addresses per hour (currently 10).</ResponseField>
    <ResponseField name="freeRemaining" type="number">Free screens remaining this hour.</ResponseField>
    <ResponseField name="freeReset" type="string">ISO 8601 timestamp when free quota resets.</ResponseField>
    <ResponseField name="billableAddresses" type="number">Number of addresses charged in this request.</ResponseField>
    <ResponseField name="creditCharged" type="number">Total credits deducted.</ResponseField>
  </Expandable>
</ResponseField>

## Rate Limiting

First **10 addresses per hour** per developer are free. After that, each address costs 1 credit.

Response headers include:
```
X-RateLimit-Free-Limit: 10
X-RateLimit-Free-Remaining: 7
X-RateLimit-Free-Reset: 2026-04-06T10:00:00.000Z
X-RateLimit-Billable: 0
```
